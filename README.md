# Hugh-Bear's Interactive Book 🐻

A touch-friendly, portrait interactive storybook for Hugh, designed for the Amazon Fire HD 10 Kids tablet.

## Getting started
Open `index.html` in a browser. Swipe left/right or use the page buttons. The first pages are **placeholders**, not the finished illustrated story.

## Story plan
School gate → sandwiches → swimming → woods → bunny → wobbly bridge → picnic → fishing → safe return. We will expand this into 20+ illustrated pages, one page at a time, with Cindy's narration.

## Files
- `index.html`: app shell
- `styles.css`: portrait-first design
- `script.js`: swipe/page navigation and optional per-page narration
- `story/pages.json`: editable page placeholders
- `assets/images/`: page illustrations (add later)
- `assets/audio/`: Cindy's recordings (add later; use page-01.mp3 etc.)

## Hosting
GitHub Pages has **not yet been enabled**. Once enabled from Settings → Pages → Deploy from a branch → `main` / root, the site can be opened on the tablet.

**Privacy:** This repository is public. Do not commit private family photos or personal recordings until you're happy for them to be publicly accessible.
